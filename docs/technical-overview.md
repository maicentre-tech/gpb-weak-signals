# ETI: технический обзор

Срез статуса: 26 сентября 2026. Приложение находится в каталоге `gpb-weak-signals/`.

## Архитектура

Пользовательский интерфейс на Next.js обращается к FastAPI. API использует PostgreSQL с расширением pgvector. Поток обработки данных состоит из адаптеров источников, общей ingestion-обвязки, нормализации и сопоставления сущностей, расчёта показателей и подготовки evidence-карточек с ссылками на первоисточники.

Основные части приложения:

- `frontend/` — интерфейс поиска, карточек и происхождения данных.
- `src/eti/sources/` и `src/eti/ingestion/` — коннекторы и общая обработка источников.
- `src/eti/ontology/` и `src/eti/scoring/` — сопоставление и расчёт показателей.
- `src/eti/rag/` — отбор доказательств и формирование карточек.
- `src/eti/api/` — HTTP API и экспертное ревью.
- `migrations/` — миграции схемы; локальный Compose запускает их при bootstrap.

## Стек

- Python 3.12, FastAPI, PostgreSQL 16 и pgvector.
- Next.js и TypeScript для интерфейса.
- Alembic для миграций.
- Docker Compose v2 для локального запуска API, UI и базы.

Языковая модель не нужна для запуска Compose. Она не заменяет проверку числовых показателей и первоисточников.

## API

При локальном запуске:

- `GET /api/v1/health` — состояние API, базы и доступного snapshot.
- `/docs` — интерактивная документация API.

Локальные адреса: `http://127.0.0.1:8000/api/v1/health` и `http://127.0.0.1:8000/docs`.

## Запуск

Выполняйте команды из каталога `gpb-weak-signals/`:

```bash
cp .env.example .env
openssl rand -hex 24
# Вставьте результат в ETI_POSTGRES_PASSWORD в .env.
docker compose up --build
```

Требуются Docker Engine и Docker Compose v2. Compose публикует порты только на loopback: UI на `127.0.0.1:3000`, API на `127.0.0.1:8000`. Конфигурация Compose и сборка frontend ранее проходили проверки, но полный чистый запуск и сквозной сценарий в этой проверке повторно не выполнялись.

## Текущие ограничения и публикационный gate

- На чистой базе нет одобренного корпуса документов и scoring snapshot; сценарий, которому нужен snapshot, не работает до загрузки разрешённых данных.
- Benchmark не предназначен для замены demo-корпуса.
- Открытый live-поиск остаётся закрытым, пока для каждого источника не подтверждены права и допустимый объём использования данных.
- Текущий стенд не имеет аутентификации. Режим только для чтения блокирует изменяющие запросы, но сам по себе не является проверкой личности.
- Проверенный публичный адрес прототипа отсутствует; не открывайте локальный Compose в интернет.
- В корне workspace и в некоторых каталогах приложения находятся материалы, права на публичное распространение которых не подтверждены. Этот workspace нельзя публиковать целиком.
- Для проекта пока не выбрана лицензия. Публичный просмотр кода сам по себе не предоставляет право на его повторное использование.
- Публичный GitHub-репозиторий не выбран и не создан; полный Git-history не проверен на ранее зафиксированные секреты.

Публичный репозиторий и ссылка на прототип появятся только после проверки прав на включаемые материалы, подготовки безопасного состава файлов, проверки истории и согласования адреса публикации.
