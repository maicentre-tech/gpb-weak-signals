# Итоговая приёмка по ТЗ

Срез: 26 сентября 2026. Сопоставлены оригинальный PDF организаторов и DOCX v1.5.

## Итог

Workspace опубликован публично; Replit сообщает об успешной сборке. Однако
опубликованный корень `/` возвращает `404`, а функциональный ETI UI/FastAPI в
deployment не зарегистрирован. Путь `/eti-jury-presentation/` отдаёт только
слайды, `/api/healthz` — health общего Node API, а ETI-маршруты
`/api/v1/health` и `/api/v1/sources/status` возвращают `404`. Поэтому экспертный
тест интерактивного стенда пока не проводился и текущую корневую ссылку нельзя
считать ссылкой на ETI-стенд.

В локальном Preview UI и API отвечают; Preview-БД содержит 18 технологий, 894
библиографические записи OpenAlex и scoring snapshot на 2026-09-26. Доменные
запросы «Технологии в ИИ», «ИИ» и «AI» возвращают все 18 карточек; alias
«агентные системы» — одну. Неизвестный запрос в read-only режиме даёт пустую
выдачу без фонового задания. Это подтверждает локальный Preview-сценарий, но не
production доступ.

Публикационный gate ETI остаётся **BLOCKED**: production-маршрут UI/FastAPI и
его состояние БД не подтверждены. Пользователь разрешил использовать только
метаданные OpenAlex в Preview; полные тексты не загружались. Поля владельца и
даты юридической проверки источников остаются пустыми, поэтому права на
production-использование не подтверждены. Прежняя Docker-БД оставлена без
изменений, данные между базами не переносились.

## Входы, нужные для закрытия блокеров

1. Одобренный demo snapshot либо корпус, воспроизводимый импорт и подтверждение прав на использование каждого источника.
2. Экспертно размеченные негативы и согласованный target для независимой ML-валидации.
3. Подтверждённый перечень используемых моделей и внешний допуск, если выбранная модель/API выходит за рамки оригинального PDF.
4. Разрешение на изменение утверждённого текста презентации, чтобы добавить стек, подробную логику ранжирования источников и бизнес-потенциал.
5. Подтверждение прав на публикацию материалов организаторов.
6. Решение по безопасному доступу: либо публичный режим только для чтения с закрытыми операциями ревью, либо аутентифицированный доступ экспертам для изменяющих действий.
7. Упаковка Next.js + FastAPI как production artifact и публикация владельцем; отдельно подтвердить наличие и подготовку production-БД ETI. Данные из Docker-БД не переносились.
