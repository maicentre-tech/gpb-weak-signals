# ETI — Emerging Technology Intelligence

ETI помогает находить и проверять слабые научно-технологические сигналы. Код приложения находится в `gpb-weak-signals/`.

## Статус публичной публикации

Этот workspace пока **не готов к публикации целиком**. В нём есть загруженные скриншоты, презентационные материалы и документы организаторов; права на их публичное распространение не подтверждены. В текущем публичном комплекте также нет назначенной лицензии проекта.

Не публикуйте корень workspace как есть и не включайте файлы из `attached_assets/`, `gpb-weak-signals/docs/original/` или `gpb-weak-signals/docs/tz/`, пока права на них не подтверждены. Публичный URL репозитория и прототипа пока не выдаётся.

## Локальный запуск

Нужны Docker Engine и Docker Compose v2. Python, Node.js и PostgreSQL отдельно устанавливать не требуется.

```bash
cd gpb-weak-signals
cp .env.example .env
openssl rand -hex 24
# Запишите результат в ETI_POSTGRES_PASSWORD внутри .env.
docker compose up --build
```

После запуска интерфейс доступен на `http://127.0.0.1:3000`, API — на `http://127.0.0.1:8000`.

- Проверка состояния: `http://127.0.0.1:8000/api/v1/health`
- Документация API: `http://127.0.0.1:8000/docs`

Для запросов к внешним источникам укажите действительный `ETI_CONTACT_EMAIL` и используйте только источники с подтверждёнными правами. Секреты храните только в локальном `.env`; не добавляйте его в Git.

## Ограничения демо

Чистый запуск создаёт схему, реестр источников и пилотную онтологию, но не загружает одобренный корпус документов или scoring snapshot. Поэтому полный сценарий поиска по snapshot на пустой базе не работает; benchmark-файл не является демонстрационной базой данных.

Стенд слушает только loopback и не имеет пользовательской аутентификации. **Не открывайте его в интернет.** Проверенная публичная ссылка на прототип отсутствует.
