# ETI — Emerging Technology Intelligence

ETI помогает находить и проверять слабые научно-технологические сигналы. Код приложения находится в `gpb-weak-signals/`.

## Материалы и условия использования

Репозиторий включает материалы, предоставленные организаторами хакатона, по прямому указанию пользователя проекта. Их наличие здесь не назначает лицензию и не предоставляет дополнительных прав на повторную публикацию или коммерческое использование; соблюдайте условия правообладателей. Общая лицензия проекта не выбрана.

## Локальный запуск

Нужны Docker Engine и Docker Compose v2. Python, Node.js и PostgreSQL отдельно устанавливать не требуется.

```bash
cd gpb-weak-signals
cp .env.example .env
openssl rand -hex 24
# Запишите результат в ETI_POSTGRES_PASSWORD внутри .env. Не добавляйте .env в Git.
docker compose up --build
```

После запуска интерфейс доступен на `http://127.0.0.1:3000`, API — на `http://127.0.0.1:8000`.

- Проверка состояния: `http://127.0.0.1:8000/api/v1/health`
- Документация API: `http://127.0.0.1:8000/docs`

Проверить контейнеры можно командами `docker compose ps` и `curl -fsS http://127.0.0.1:8000/api/v1/health`. Для остановки выполните `docker compose down`: именованный volume базы сохранится. Не используйте `docker compose down -v`, если не хотите удалить данные.

Для запросов к внешним источникам укажите действительный `ETI_CONTACT_EMAIL`. Реальные пароли, ключи и токены храните вне Git; `.env.example` содержит только шаблонные значения.

## Ограничения демо

Чистый запуск создаёт схему, реестр источников и пилотную онтологию, но не загружает корпус документов или scoring snapshot. Поэтому полный сценарий поиска по snapshot на пустой базе не работает; benchmark-данные не являются демонстрационной базой.

Локальный Compose-стенд слушает только loopback и не имеет пользовательской аутентификации. **Не открывайте его в интернет.** Публичный Replit deployment — отдельная конфигурация; его текущий статус и ограничения приведены в технической документации.
